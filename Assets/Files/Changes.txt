1)Session Management Issues(Done)

2)Query Optimization Issues:(Done)
    Multiple separate queries where single JOINs would be more efficient(Yes)
    For example:
        In userProduct.cfm you’re making one call for the product details (using selectAllProducts) on (roughly) line 16 and then a second call for the product images (using selectProductImages) on line 17.
        This can be optimized by using a single query with a JOIN between the product and product images tables.

3)Missing Pagination in all places needed:
    Hard-coded limits without proper pagination.
    Use LIMIT and OFFSET to paginate the results.(Changed)

4)Error Handling Issues:(Done)	
    No error handling in the application.cfc

5)Issues with the Image Upload Handling(Done)
    No File Type Validation(Changed)
    There is no check to verify that the uploaded files are valid image types (such as .jpg, .png, or .gif).
    Without this validation, users might upload non-image files or even malicious scripts, which can create security risks.

    No File Size Restrictions(Changed)
    This could allow extremely large files to be uploaded, which may lead to longer load times or even performance bottlenecks on the server.

6)Application.cfc issues:
